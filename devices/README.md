# Supported devices

Select the exact device before following the [installation
workflow](../README.md#install-a-supported-device).

| Platform and layout | Device | Verified support |
|---|---|---|
| ESP8266 non-OS V2 | [Petkit Fresh Element Mini](esp8266/nonos_v2/fresh-element-mini/) | SoftAP provisioning, local startup API, stock OTA, backup, and recovery |

Support for a similar Petkit model must not reuse a profile until its API
fields, provisioning protocol, firmware format, flash boundaries, and recovery
procedure have been verified on that model.
